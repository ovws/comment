# 电商主图检查器 / Ecommerce Main Image Review

一个纯静态、纯浏览器本地运行的商品主图预览与点击测试工具。

## 功能

- 支持淘宝 / 抖音商城 / 拼多多界面切换
- 一次批量上传多张 1:1 商品主图
- 自动生成手机端双列瀑布流商品卡片
- 点击任意商品卡片进入对应 3:4 商品详情大图预览
- 自定义商品标题、价格、销量
- 支持拖拽、点击选择、剪贴板粘贴图片
- 支持继续追加图片、删除最后一张、清空全部
- 图片只在浏览器本地处理，不上传服务器
- 手机和桌面端自适应

## 使用方式

1. 选择要模拟的平台。
2. 一次上传多张 1:1 商品主图。
3. 在瀑布流中观察主图缩小后的第一眼表现。
4. 点击任意商品进入 3:4 详情大图界面。
5. 切换淘宝、抖音商城或拼多多，对比不同平台环境下的视觉效果。

## 部署

项目为零依赖静态站点，可直接部署到 Vercel。
