# 电商主图检查器 / Ecommerce Main Image Review

一个纯静态、纯浏览器本地运行的商品主图预览与点击测试工具。

## 功能

- 支持淘宝 / 抖音商城 / 拼多多界面切换
- 一次批量上传多张 1:1 商品主图，用于手机端双列瀑布流
- 独立批量上传多张 3:4 商品详情图
- 1:1 与 3:4 按顺序自动一一配对
- 点击任意商品卡片进入对应的 3:4 商品详情大图预览
- 支持在详情页单独替换或移除当前商品的 3:4 图片
- 未上传独立 3:4 时，会临时用对应 1:1 主图进行 3:4 裁切模拟
- 自定义商品标题、价格、销量
- 支持拖拽、点击选择、剪贴板粘贴 1:1 图片
- 支持继续追加图片、删除最后一个商品、清空全部 3:4、清空全部素材
- 图片只在浏览器本地处理，不上传服务器
- 手机和桌面端自适应

## 使用方式

1. 选择要模拟的平台。
2. 批量上传多张 1:1 商品主图。
3. 批量上传对应的 3:4 商品详情图，系统会从第一个未绑定 3:4 的商品开始按顺序匹配。
4. 在瀑布流中观察 1:1 主图缩小后的第一眼表现。
5. 点击任意商品，查看该商品对应的独立 3:4 详情图。
6. 如需调整某一商品，可在详情页单独替换当前 3:4 图片。
7. 切换淘宝、抖音商城或拼多多，对比不同平台环境下的视觉效果。

## 部署

项目为零依赖静态站点，可直接部署到 Vercel。
